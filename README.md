# Margia — Conoce tu costo. Cuida tu margen.

Costeo estándar para negocios que producen. Aplicación local de costeo estándar por producto: materias primas, mano de obra
directa y CIF, con seguridad de usuarios/roles, validaciones y bitácora.
No necesita internet para funcionar.

## Ejecutar

```
python iniciar.py
```

Se abre solo en el navegador. Usuarios iniciales: `admin` / `admin123` y
`estudiante` / `estudiante123`.

## Generar el .exe

Ver `installer/INSTALAR.txt`.
